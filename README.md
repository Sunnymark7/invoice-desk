# 票据台

本地票据整理工具，支持浏览器与 Tauri Windows 桌面版。

- 空白页只有文件导入入口；添加文件后自动进入票据工作区，右侧加号可以继续添加。
- 支持 PDF、OFD、JPG、PNG、WebP，票据在本机解析。
- 列表与网格共用同一份数据和导出顺序。
- 按开票时间或销售方公司名称正序、倒序排列，也可恢复导入顺序或自动配对凭证。
- 点击卡片、按住 Ctrl 加选、按住 Shift 连选，或从票据间的空白区域拖动框选；未选中任何卡片时隐藏勾选框。卡片不显示页数与发票号码。
- 选中后拖动票面或行首拖动柄，卡片跟随鼠标移动。靠近其他卡片时，两侧会让出空隙并显示插入线；松手后整体放入，保留多选票据的相对顺序。顶部序号仅作顺序标记，不可编辑。
- 鼠标悬停票面时显示放大镜，点击票面可放大、缩放、旋转及核对字段。
- 红色表示待核对，绿色表示信息完整或已识别的附件。附件不计入金额。
- 多页发票保持整体移动，金额只计算一次；支持逐页删除与撤销。
- 右上角导出 CSV 明细与合并 PDF；导出始终包含全部保留票据，使用当前排序。
- IndexedDB 自动保存原文件、修改和顺序。保存失败时会显示提示。
- PDF 可拖进整个浏览器窗口或桌面窗口。

OCR 首次使用需要下载中英文识别模型，票据图像仍在本机处理。

## 本地运行

```powershell
npm install
npm run dev
```

打开 `http://127.0.0.1:4173/`。

## Windows 桌面版

需要 Rust MSVC、Visual Studio C++ Build Tools 和 WebView2。

```powershell
npm run desktop
npm run desktop:build
```

桌面版导出使用 Windows 原生保存窗口。安装包位于 `src-tauri/target/release/bundle/nsis/`。

## 本地 Git

本项目只做本地 Git 提交，不推送 GitHub、不上传发布、不自动部署。
本地 `origin` 的推送地址已禁用，并启用 `.githooks/pre-push` 拦截远程推送。

可手动运行 `npm test` 与 `npm run check`。本轮最终界面修改按用户要求不再运行测试或界面验证。

图标来自 Bootstrap Icons 1.13.1，许可见 `dist/vendor/icons/LICENSE.txt`。



导入或继续追加票据后，默认按开票时间从早到晚重新排序；未知日期置后。悬停合计金额可放大查看，点击复制两位小数价格。

卡片使用更大的高清票面预览，序号位于票据左侧，文件名是主要标题，公司名称弱化显示。

列表和网格的序号均位于卡片外侧；类别与价格在同一行，类别靠右。

右侧加号下方的视图缩放按钮展开竖向比例尺，可在 60%–160% 间调整票据界面，也可恢复 100%。每次调节立即保存为本机偏好，下次打开或开始新批次时继续使用上次比例；兼容恢复旧草稿里的比例。

选中票据后显示全选与批量删除，整批删除可撤销。删除最后一张后回到初始导入页，短暂保留撤销提示；也可按 Ctrl+Z 恢复。比例尺只调整卡片，统计、筛选、排序与其他工具保持原比例。点击圆形缩放控件，端点展开为竖向尺子；移出后合拢。页面两侧空白也可发起框选。

排序支持主排列与副排列：先按主字段排序，仅在主字段相同时按副字段继续排列。开票时间、价格、公司名称均支持正序和倒序；副排列可以不使用。

主界面不显示品牌 header；两个导出按钮位于统计栏附件右边。删除提示和短提示均带关闭按钮，关闭不会清除撤销历史。缩放控件支持悬停展开并保持顶部端点固定在原按钮处。

默认卡片比例为 80%。列表视图低于 100% 时，文字维持原字号；100% 以上随卡片放大。统计和工具栏始终保持原比例。

界面为右侧圆形工具固定预留独立空间，窄窗口的筛选与排序区独立横向滚动，搜索和视图切换保持固定，避免与添加票据按钮重叠。

搜索支持价格及货币格式，例如 9.7、9.70、¥9.70 和 9.70元。网格票面区域去除顶部内边距；卡片删除按钮为红底白叉，悬停放大。

票面核对窗口将文件名集中在右侧标题栏，移除顶部重复标题及页数、类别、金额摘要。底部的页码输入位于缩放和旋转之间，输入后按回车或移开焦点可按当前保留页面顺序跳转；未保存的修改仍会阻止切换。左右翻页按钮扩大并显示文字，滚轮支持连续切换及触控板惯性抑制，新票面完成绘制后再替换当前票面。

保存人工核对后，对应项目的每个保留页面缩略图左上角显示绿色对号，随草稿恢复。选中数量、全选和批量删除位于左侧，选中数量使用深色底和对号强调；未选中时整行隐藏。不再显示“共若干条明细”统计行。网格卡片的日期与公司在同一行，公司较长时省略显示。

选中票据后，左侧操作栏显示“按顺序合并 PDF”。只导出选中的项目，采用当前排列顺序，而非点击选择的先后顺序；多页票据保留全部尚未删除的页面及其页序，附件也按选中情况保留。文件名中的金额只汇总选中项目内计入合计的票据。顶部“导出合并 PDF”仍导出整批保留页面。
