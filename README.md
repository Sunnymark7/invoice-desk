# 票据台

本地票据整理工具，支持浏览器与 Tauri Windows 桌面版。

工作区“功能说明”可展开查看各项操作范围。“待核对”统计可直接筛选，计入合计的待核对金额会单独提示。主按钮“导出整批 PDF”导出全部保留页面；选择卡片后的“合并选中”仅导出所选票据，均使用当前排序。卡片标明待核对、已识别、已核对或附件；“替换整票”更换该张发票的全部页面，叉号只删除一页。

每张票据可点击“选择”加选，无需键盘。搜索和状态筛选保留已选项目，选择栏显示隐藏数量；“显示全部票据”清除筛选，“取消选择”清除全部选择，“全选当前”只操作当前可见项目。合并/删除选中均包含已提示的隐藏选择。从筛选结果进入核对时，只在打开窗口时的结果范围内翻页；保存后保留该范围，关闭再打开可重新选取范围。

手机窗口使用横向票据工具，内容不再为右侧工具栏预留宽度。核对窗口的票面、预览工具、滚动表单和固定保存区分别占位；点击票面直接预览，“选择”按钮负责多选，避免首次点击时布局跳动。

卡片上的“选择 / 替换”使用同排图标按钮，选中时显示对号及“已选”；替换仍作用于整张发票。卡片缩放时操作区保持固定点击尺寸。窄手机网格采用单列，侧边工具在桌面独立放大。

添加按钮角标显示整批当前保留的票据条目数：包含附件和待核对，多页同票算一条；重复排除项不计入，筛选不改变总数。它与上方“计费发票”数量口径不同，鼠标悬停可查看说明；删掉最后一页、撤销、替换和追加后同步更新。

侧边标尺采用约200ms淡入缩放，端点不再改变布局尺寸。移出边缘有短暂缓冲；拖动或键盘聚焦时保持展开，外部点击或Esc可关闭。键盘与减少动态效果模式即时响应。

页面右下角使用用户提供的元思图形标识作为浅色底纹，仅显示原图左侧图形，不显示中英文文字。底纹随窗口尺寸自适应并保留边距，不拦截点击；不写入导出的发票 PDF。

- 空白页只有文件导入入口；添加文件后自动进入票据工作区，右侧加号可以继续添加。
- 支持 PDF、OFD、JPG、PNG、WebP，票据在本机解析。
- 列表与网格共用同一份数据和导出顺序。
- 按开票时间或销售方公司名称正序、倒序排列，也可恢复导入顺序或自动配对凭证。
- 点击卡片、按住 Ctrl 加选、按住 Shift 连选，或从票据间的空白区域拖动框选；未选中任何卡片时隐藏勾选框。卡片不显示页数与发票号码。
- 选中后拖动票面或行首拖动柄，卡片跟随鼠标移动。靠近其他卡片时，两侧会让出空隙并显示插入线；松手后整体放入，保留多选票据的相对顺序。顶部序号仅作顺序标记，不可编辑。
- 鼠标悬停票面时显示放大镜，点击票面可放大、缩放、旋转及核对字段。
- 红色表示待核对，绿色表示信息完整或已识别的附件。附件不计入金额。
- 多页发票保持整体移动，金额只计算一次；支持逐页删除与撤销。
- 右上角导出 CSV 明细与合并 PDF；导出始终包含全部保留票据，使用当前排序。
- IndexedDB 自动保存原文件、修改和顺序。保存失败时会显示提示。
- PDF 可拖进整个浏览器窗口或桌面窗口。

OCR 首次使用需要下载中英文识别模型，票据图像仍在本机处理。

## 本地运行

```powershell
npm install
npm run dev
```

打开 `http://127.0.0.1:4173/`。

## Windows 桌面版

需要 Rust MSVC、Visual Studio C++ Build Tools 和 WebView2。

```powershell
npm run desktop
npm run desktop:build
```

桌面版导出使用 Windows 原生保存窗口。安装包位于 `src-tauri/target/release/bundle/nsis/`。

## GitHub 与线上部署

用户已于 2026-11-01 授权更新 GitHub 并部署线上版本。推送 `main` 后，GitHub Actions 将 `dist` 发布至 [GitHub Pages](https://sunnymark7.github.io/invoice-desk/)。不使用 Sites。
`.githooks/pre-push` 保持启用，只允许授权仓库的 `main` 分支。发票样本、导出文件和浏览器草稿不上传。

用户已授权本机识别回归，可运行 `npm test` 与 `npm run check`。浏览器和 Tauri 的实际界面交互仍需单独验收。

图标来自 Bootstrap Icons 1.13.1，许可见 `dist/vendor/icons/LICENSE.txt`。



默认不自动重排，首次导入保持文件导入顺序和原始页序，追加票据接在末尾。只有用户主动选择日期、金额、销售方或配对方式时才按该规则排序；之后追加沿用用户选择的排序。手动排序保留已有位置，并把新增票据追加到末尾。已保存批次的顺序保持不变，可选择“导入顺序”恢复。悬停合计金额可放大查看，点击复制两位小数价格。

卡片使用更大的高清票面预览，序号位于票据左侧，文件名是主要标题，公司名称弱化显示。

列表和网格的序号均位于卡片外侧；类别与价格在同一行，类别靠右。

右侧工具栏最下方的刻度尺图标按钮展开竖向比例尺，可在 60%–160% 间调整票据界面，也可恢复 100%。每次调节立即保存为本机偏好，下次打开或开始新批次时继续使用上次比例；兼容恢复旧草稿里的比例。

选中票据后显示全选与批量删除，整批删除可撤销。删除最后一张后回到初始导入页，短暂保留撤销提示；也可按 Ctrl+Z 恢复。比例尺只调整卡片，统计、筛选、排序与其他工具保持原比例。点击圆形缩放控件，端点展开为竖向尺子；移出后合拢。页面两侧空白也可发起框选。

排序支持主排列与副排列：先按主字段排序，仅在主字段相同时按副字段继续排列。开票时间、价格、公司名称均支持正序和倒序；副排列可以不使用。

主界面不显示品牌 header；两个导出按钮位于统计栏附件右边。删除提示和短提示均带关闭按钮，关闭不会清除撤销历史。缩放控件支持悬停展开并保持顶部端点固定在原按钮处。

默认卡片比例为 80%。列表视图低于 100% 时，文字维持原字号；100% 以上随卡片放大。统计和工具栏始终保持原比例。

界面为右侧圆形工具固定预留独立空间，窄窗口的筛选与排序区独立横向滚动，搜索和视图切换保持固定，避免与添加票据按钮重叠。

搜索支持价格及货币格式，例如 9.7、9.70、¥9.70 和 9.70元。网格票面区域去除顶部内边距；卡片删除按钮为红底白叉，悬停放大。

票面核对窗口将文件名集中在右侧标题栏，移除顶部重复标题及页数、类别、金额摘要。底部的页码输入位于缩放和旋转之间，输入后按回车或移开焦点可按当前保留页面顺序跳转；未保存的修改仍会阻止切换。左右翻页按钮扩大并显示文字，滚轮支持连续切换及触控板惯性抑制，新票面完成绘制后再替换当前票面。

保存人工核对后，对应项目的每个保留页面缩略图左上角显示绿色对号，随草稿恢复。选中数量、全选和批量删除位于左侧，选中数量使用深色底和对号强调；未选中时整行隐藏。不再显示“共若干条明细”统计行。网格卡片的日期与公司在同一行，公司较长时省略显示。

选中票据后，左侧操作栏显示“按顺序合并 PDF”。只导出选中的项目，采用当前排列顺序，而非点击选择的先后顺序；多页票据保留全部尚未删除的页面及其页序，附件也按选中情况保留。文件名中的金额只汇总选中项目内计入合计的票据。顶部“导出合并 PDF”仍导出整批保留页面。

右侧的三个圆形按钮，分别使用专门绘制的文档标题、公司楼宇、日历图标，可独立隐藏或恢复卡片上的 PDF 标题、公司名称、开票时间，同时适用于列表和网格。比例尺位于这三个开关下方，是工具栏最后一项；展开后的上下融球端点缩小为 16px，并保留透明点击余量。悬停显示文字说明，斜线图标表示该项已隐藏；设置立即保存在本机，下次打开、恢复草稿或开始新批次时沿用。仅调整卡片显示，搜索、核对、排序、金额及导出仍保留完整信息。

缩略图删除按钮使用固定 44px 点击范围，悬停时只放大内部可见图标，避免点击区扩大导致意外滚动。

## 单张发票替换

- 每张卡片的“替换”，以及票面核对侧栏的“替换整张发票”，可选择一份 PDF、OFD、JPG、PNG 或 WebP 文件。
- 替换范围为当前整张发票的全部保留页面；同一原始合并 PDF 中的其他发票不受影响。多页同一发票仍只计一次金额。
- 新文件独立识别后才替换，重新提取票面字段并清除原人工核对标记；不沿用旧金额，也不从文件名推断金额。未识别内容标为待核对。
- 读取失败、与本批其他票据重复、包含多张独立发票的文件不会替换原票。原始磁盘文件不会被修改。
- 保留当前排列位置，主排列切换为“手动调整”；如需按新日期重排，可重新选择开票时间排序。
- 列表提示或当前核对侧栏可以“撤销替换”，也可在列表按 Ctrl+Z。原票、新票及撤销记录均保存在本机草稿中；未保存的表单修改须先保存或重置。
- 原文件和替换文件保留到清空批次，以便撤销；多次替换会增加本地草稿占用。

审核记录和待手动验证的场景见 [review-20261101.md](review-20261101.md)。该报告记录了最初的静态审阅范围；后续授权的识别回归结果见下文。

## 清空与识别增强（2026-11-01）

- 统计栏“清空本批”一键移除本批票据、选择、撤销记录及本机草稿；保留磁盘原文件和卡片显示偏好。识别与导出期间禁用。
- 减少空白页、统计栏和核对窗口的重复说明，只在异常、未保存或处理中显示必要提醒。
- PDF/OFD 有文字但关键字段缺失时补充 OCR；原始文字和 OCR 分开提取，按字段补缺，保留原有有效数据和文本行结构。
- 金额支持全角数字和财务大写；大小写交叉核对，冲突或未找到可靠合计时待核对，不将明细单价或税额猜成总额。
- 优先提取开票日期并检查真实日历；缺失票号保持待核对。仅包含商品价格的截图不自动作为发票计入合计。
- 本机 20 份带文字 PDF、44 页回归为 34 张计费票据、5592.66 元；35 项自动化检查通过。真实扫描件 OCR 的效果仍取决于清晰度，异常项保留人工核对。

比例尺的尺轴、上下端点和白色滑块共用中心线；百分比与滑块共用纵向位置，白色滑块悬停或拖动时保持居中放大。搜索按钮采用 12px 圆角矩形，在原位置向左融合展开为相同圆角的搜索框，再次点击、按 Esc 或移出焦点可收起。

界面统一使用圆角规则：右侧独立图标工具为正圆，搜索、文字按钮和输入控件为 12px 圆角，组合工具为 16px 外圆角、12px 内圆角及 4px 内间距。工具栏筛选、下拉框和视图切换采用相同高度；卡片与统计容器采用 16px 圆角。
