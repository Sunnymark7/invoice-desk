# 票据台 · 发票整理工作台

浏览器端发票整理工具。原始票据在本地解析，不上传到应用服务器。

## 功能

- 支持 PDF、OFD、JPG、PNG、WebP；按文件真实内容判断格式，不依赖扩展名或文件名
- 将合并 PDF/OFD 按页面拆为独立票据单元，并显示真实票面缩略图
- 同一发票跨多页时按发票号码合并为一条明细，同时保留全部页面用于预览、排序和导出
- 识别增值税发票、滴滴发票与行程单、航空发票/凭证/行程校验单、铁路电子客票等票据
- 提取日期、票号、销售方、类别和金额，并计算合计
- 按票面坐标重建阅读顺序，识别旋转版式、铁路票价、免税/代开票销售方及价税合计，区分研发耗材和保险
- 修改字段时并排预览真实票面，支持拖动和缩放
- 独立排序匹配页支持拖动页面；同一航班按“登机凭证 → 航空发票 → 行程校验单”聚合
- 默认按文件导入顺序和原始页序保留；可手动恢复导入顺序、按开票日期排序或按机票/打车规则配对
- 无法识别的截图和页面保留为“待核对”，不计入金额但可预览、修改和导出
- 相同发票自动去重，不重复计入金额或合并文件
- 导出 CSV 明细和合并 PDF
- 同一批次可持续追加文件，保留已有修改及排序；相同文件或重复发票不会重复计费
- 预览和核对窗口均可旋转 90°；多页发票核对时可以切页，预览旋转不修改原始文件

## 本地运行

静态文件位于 `dist/`。使用任意静态服务器打开即可，例如：

```powershell
python -m http.server 4173 --directory dist
```

然后访问 `http://127.0.0.1:4173`。

## GitHub Pages

仓库包含 GitHub Pages 工作流。推送到 `main` 分支后，在仓库的 **Settings → Pages** 中将 Source 设为 **GitHub Actions**，后续推送会自动发布 `dist/`。

> 文本型 PDF 完全在浏览器中解析；需要 OCR 时，浏览器会下载中文和英文识别模型，票据图片仍在本机处理。
