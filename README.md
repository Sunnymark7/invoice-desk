# 票据台 · 发票整理工作台

浏览器端 PDF 发票整理工具。原始票据在本地解析，不上传到应用服务器。

## 功能

- 识别增值税发票、滴滴发票与行程单、航空凭证、行程校验单、铁路电子客票等 PDF 票据
- 提取日期、票号、销售方、类别和金额，并计算合计
- 在核对时预览 PDF，支持拖动和缩放
- 拖动调整合并顺序，并按票面航班号自动配对凭证
- 导出 CSV 明细和合并 PDF

## 本地运行

静态文件位于 `dist/`。使用任意静态服务器打开即可，例如：

```powershell
python -m http.server 4173 --directory dist
```

然后访问 `http://127.0.0.1:4173`。

## GitHub Pages

仓库包含 GitHub Pages 工作流。推送到 `main` 分支后，在仓库的 **Settings → Pages** 中将 Source 设为 **GitHub Actions**，后续推送会自动发布 `dist/`。

> 文本型 PDF 完全在浏览器中解析；需要 OCR 时，浏览器会下载中文和英文识别模型，票据图片仍在本机处理。
